# YouTube Clone Website

A responsive **YouTube website clone** built as a learning project while practicing **Git and GitHub**. This project helped me understand how to manage a real-world project using version control and how to track, commit, and manage changes throughout the development process.

## 📌 About The Project

This project is a frontend clone of the YouTube website, created for educational and practice purposes. The main goal was to recreate the basic look and structure of YouTube while simultaneously learning how **Git and GitHub** are used in software development.

While building this project, I practiced important Git concepts such as creating repositories, tracking files, making commits, viewing project history, and managing changes.

## ✨ Features

* YouTube-inspired user interface
* Responsive website layout
* Navigation sidebar
* Video thumbnail section
* Video cards with titles and channel information
* Clean and simple UI
* Organized project structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## 📚 What I Learned

Through this project, I gained practical experience with:

* Creating and initializing a Git repository
* Using `git init`
* Checking changes with `git status`
* Tracking files using `git add`
* Creating commits with `git commit`
* Viewing commit history using `git log`
* Working with GitHub repositories
* Pushing local code to GitHub
* Understanding version control
* Managing project changes using Git

## 🎯 Purpose

This project was created mainly for **learning and practice**. It helped me improve my frontend development skills while also getting hands-on experience with Git and GitHub, which are important tools used in modern software development.
